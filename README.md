# Bible & Songbook

An offline-focused Android KJV Bible and Lutheran hymn/songbook application with optional offline Bible study resources.

The Bible, songbook, notes, bookmarks, highlights, favorites, reading progress, and installed study resources are designed to work without an active internet connection.

## Download and install

The latest Android APK is available from the repository's **Releases** page.

Latest release:

**v1.2.6**

Download:

`KJV-Bible-and-Songbook-v1.2.6.apk`

Open the APK on your Android device and follow the installation prompt.

Android may ask you to allow installation from your browser or file manager because the app is distributed directly rather than through Google Play.

## Bible features

- Complete King James Version (KJV) Bible
- Offline Bible reading
- Navigation by book, chapter, and reference
- Swipe left/right between chapters
- Previous and next chapter controls
- Resume your last reading position
- Reading progress tracking
- Favorite verses
- Bookmarks
- Persistent text highlighting with multiple colors
- Personal notes
- Copy and share selected Scripture
- Search the web for selected text using your external browser
- Adjustable Bible text size
- Serif or Android system font
- Adjustable line spacing
- Light, dark, and AMOLED themes
- Optional red-letter Words of Christ

## Bible Study

The app supports optional downloadable Bible study resources.

Once installed, study data is stored on the device and can be used offline.

### Definition

Select text in the Bible and choose **Study** to look up definitions.

The optional dictionary resources can provide:

- English word definitions
- Bible dictionary entries
- Biblical people
- Biblical places
- Biblical subjects and terms

For example, selecting the name of a biblical person can provide information explaining who that person is.

### Strong's & Morphology

The optional Full Bible Study Pack provides original-language study information including:

- Strong's numbers
- Hebrew and Greek words
- Lemmas
- Transliteration and pronunciation
- Lexical definitions
- KJV usage information
- Hebrew and Greek morphology
- Original-language verse analysis

The Study screen separates **Definition** and **Morphology** into dedicated views.

## Red-letter Bible

Optional red-letter data identifies the Words of Christ at the word/phrase level rather than simply coloring entire verses.

The data can be downloaded from Settings and is available offline after installation.

Red-letter display can be turned on or off at any time.

## Songbook

- 673 hymns
- Search by title, number, or words
- Song categories
- Favorite songs
- Swipe left/right between songs
- Offline access

The song collection is organized and numbered to correspond with *Hymns and Songs of Zion*, the hymnal used in Apostolic Lutheran congregations.

This allows the app to be used alongside the physical hymnal while keeping familiar hymn numbers and organization.

This is an independent project and is not an official application of, sponsored by, or affiliated with the Apostolic Lutheran Church of America or its Book Concern.

## Privacy

Bible & Songbook is designed as an offline-focused application.

The following information and features are stored locally on the device:

- Bible and songbook content
- Favorites
- Bookmarks
- Highlights
- Notes
- Reading progress
- Reader settings
- Installed study resources

The app does not include advertising or analytics.

### Internet access

The Android application requests the `INTERNET` permission so that optional data packs and Bible study resources can be downloaded when requested by the user.

Internet access is used for user-initiated functions such as:

- Downloading red-letter data
- Downloading Bible study data
- Downloading dictionaries and commentaries
- Downloading additional supported Bible translations
- Re-downloading or updating supported resources

The Bible reader's WebView does not act as a general-purpose web browser.

When **Web Search** or an external source/attribution link is selected, the request is handed to the device's external browser.

Normal Bible reading, songbook use, notes, highlights, bookmarks, favorites, reading progress, and already-installed study resources do not require an internet connection.

## Offline-only mode

For users who prefer not to have the app download study resources itself, **Offline-only mode** is available in Settings.

When using this option, supported data packs can be downloaded independently and imported into the app using Android's system file picker.

This allows users to obtain and inspect the source data themselves before installing it.

See **Sources & Offline Import** inside the app for information about supported resources and manual installation.

## Data sources and attribution

Bible & Songbook uses or can optionally use data from multiple public-domain and open-source projects for Bible text, red-letter information, dictionaries, Strong's information, Hebrew/Greek linguistic data, and other study resources.

Each third-party dataset retains its own copyright, license, and attribution requirements.

The license covering this application's original source code does **not** automatically apply to third-party Bible text, hymn text, dictionary data, linguistic datasets, or artwork.

Source and licensing information for optional study resources is available through **Sources & Offline Import** inside the application and through the respective upstream projects.

## Local data

Favorites, bookmarks, highlights, notes, reading progress, downloaded study resources, and application settings are stored locally on the device.

Uninstalling the application may remove locally stored application data.

Updates signed with the same application signing key can normally be installed over an existing version without removing local data.

> **Signing key notice:** v1.2.6 begins using the new release signing key intended for future releases. Builds signed with an older key may need to be uninstalled before installing v1.2.6.
